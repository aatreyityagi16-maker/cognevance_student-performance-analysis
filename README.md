# Student Performance Analysis

## Project Overview
This project analyzes student attendance and academic performance using Python and Pandas.

## Tasks Covered
- Data collection using a sample student dataset
- Data cleaning and preprocessing
- Analysis of marks, attendance, and performance trends
- Bar chart, histogram, and pie chart visualizations
- Relationship analysis between attendance and academic scores
- Insights and recommendations
- Short project report

## Files
- `student_performance_dataset.csv` — student dataset
- `analysis.py` — Python analysis and visualization code
- `average_marks_by_subject.png` — subject-wise average marks
- `average_marks_histogram.png` — distribution of average marks
- `performance_categories_pie.png` — performance categories
- `attendance_vs_marks.png` — attendance vs average marks
- `project_report.pdf` — short project report

## Key Result
The correlation between attendance and average marks in this sample is **1.00**, indicating a positive relationship: students with higher attendance generally tend to have higher academic scores.

## Tools
Python, Pandas, NumPy, Matplotlib
